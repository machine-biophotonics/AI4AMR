================================================================================
                              KEY COMPONENTS
================================================================================

1. BACKBONE (EfficientNet-B0)
   - Pretrained on ImageNet
   - Modified for 1-channel grayscale input
   - Output: 1280-dimensional features per crop

2. ATTENTION POOLING (Gated Multi-Head)
   - 4 parallel attention heads
   - Gated mechanism: tanh(V(x)) × sigmoid(U(x))
   - Temperature = 0.5 (sharpens attention distribution)
   - Learns which crops are most informative

3. CLASSIFIERS (2 levels)
   - Bag classifier: dropout(0.5) → linear(1280→89)
   - Instance classifier: dropout(0.5) → linear(1280→89)

4. OPTIONAL: SC-MIL (Supervised Contrastive)
   - ContrastiveEncoder for contrastive learning
   - Projects 1280 → 256 → 256
   - Temperature: 0.07
